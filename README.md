# End City Detector (Fabric, Minecraft 26.2)

Клиентский мод: в Энде следит за тем, что сервер прислал клиенту, и оповещает
сообщением в чате с координатами и звуком, когда видит признаки Энд-города:
шалкеры, пурпурные блоки, рамки с элитрами (корабль Энда).

- `K` — настройки (что искать, звук, громкость, порог пурпура, дистанция повтора)
- `L` — список найденных признаков в чат
- Видит только то, что сервер прислал клиенту (в пределах дальности прорисовки).
- Для проверки в одиночной игре выключи «Только в Энде» и призови шалкера: /summon shulker

Сборка: любой push запускает GitHub Actions, jar лежит в артефакте `endcitydetector-jar`.
